# Portfolio

My personal portfolio site, built with Next.js and Tailwind CSS.

## Features

- Light/dark mode with a toggle (remembers your choice)
- Projects section
- Downloadable resume
- Responsive and accessible

## Tech

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customize

- Name, bio, links, and projects: `lib/content.ts`
- Resume: replace `public/resume.pdf`
- Colors: CSS variables in `app/globals.css`

## Deploy

Push to GitHub and import the repo into [Vercel](https://vercel.com).
